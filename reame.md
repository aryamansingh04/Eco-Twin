# Industrial Sustainability & Digital Twin Platform

A cloud-based industrial sustainability platform that combines **factory digital twins, machine telemetry, energy and carbon analytics, production intelligence, and machine learning** to help industries monitor and improve operational and environmental efficiency.

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Three.js / React Three Fiber
- Tailwind CSS
- Recharts

### Backend
- Python
- Django
- Django REST Framework

### Data & Analytics
- Pandas
- NumPy
- Scikit-learn

### Google Cloud
- Cloud Run
- Cloud SQL
- BigQuery
- Vertex AI
- Cloud Storage

### Database
- SQLite (local development)
- PostgreSQL / Cloud SQL (production)
